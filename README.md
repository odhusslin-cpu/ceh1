# Цех

Личный трекер: день, неделя, месяц, изделия, заказы с расчётом себестоимости.

## Как поставить на телефон

1. Создай на GitHub новый репозиторий, назови `ceh`, поставь Public.
2. Загрузи в него все файлы из этой папки: `index.html`, `sw.js`, `manifest.webmanifest`, `icon-180.png`, `icon-192.png`, `icon-512.png`.
3. В репозитории: **Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save**.
4. Через пару минут появится адрес вида `https://ИМЯ.github.io/ceh/`.
5. Открой этот адрес на телефоне в Safari (iPhone) или Chrome (Android).
6. Кнопка «Поделиться» → **На экран «Домой»**. Появится иконка.

Дальше приложение открывается в одно касание, работает без интернета и на весь экран.

## Копии данных

Всё лежит в браузере телефона. Вкладка **Цели → Копии**.

**Снимки по неделям** работают сами: раз в неделю трекер откладывает состояние, хранит десять последних, любой можно откатить. Защищает от собственных ошибок, но не от потери телефона.

**Автокопия на GitHub** — раз в неделю при открытии приложения молча отправляет файл в приватный репозиторий. Настройка один раз:

1. Создай второй репозиторий, например `ceh-data`, **обязательно Private**.
2. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
3. Repository access: Only select repositories → `ceh-data`. Permissions: Repository permissions → **Contents: Read and write**.
4. Скопируй токен, в приложении: Цели → Копии → **Подключить репозиторий**. Впиши `твойник/ceh-data` и токен.

Файл ляжет в `backups/ceh.json`, каждая новая копия — новый коммит. История коммитов и есть архив: видно все недели и что менялось.

Токен живёт только в памяти твоего телефона, в публичный репозиторий он не попадает. У fine-grained токенов есть срок действия — когда истечёт, в блоке копий появится ошибка, просто выпусти новый.

**Вручную**: «Выгрузить файл» или «Скопировать». Перенос на другой телефон: «Скопировать» на старом, «Загрузить копию» на новом.

Чистка истории Safari с удалением данных сайтов сотрёт трекер — поэтому автокопия.
